# 오우케이 설비 홈페이지

GitHub Pages용 정적 홈페이지입니다. 누수 탐지·보수, 저온창고, 에어컨 설비를 소개합니다.

## 견적 문의

홈페이지에는 단가와 자동 견적 계산기를 표시하지 않습니다. 견적 문의와 현장사진 상담 버튼은 오우케이설비 카카오톡 채널 `https://pf.kakao.com/_HxjExiX/chat`로 연결됩니다. 고객은 채팅창에서 현장 조건과 사진을 보내고, 담당자가 개별 상담 후 견적을 안내합니다. 채널 주소를 변경할 때는 `index.html`의 모든 채널 링크를 함께 변경하세요.

사이트의 개인정보 안내 문구는 홈페이지에 별도의 고객정보 입력란이 없다는 점을 설명합니다. 채널 채팅으로 전달된 내용은 상담 담당자가 확인하므로 개인정보 보호를 절대적으로 보장하는 표현은 사용하지 않습니다.

## 운영 정보

`script.js` 상단의 `SITE_CONFIG`에서 전화번호, 상담시간과 사업자 정보를 확인하세요. 현재 사업자 정보는 입력 대기 문구입니다. `index.html`의 회사 소개와 시공 분야도 실제 업무에 맞게 검토하세요.

## 컴퓨터에서 확인하기

`index.html`을 브라우저에서 열어 화면을 확인할 수 있습니다. 모바일과 PC에서 카카오톡 채널 링크가 열리는지 각각 확인하세요.

## GitHub Pages 배포

저장소 최상단의 파일을 갱신하면 GitHub Pages 설정에 따라 사이트에 반영됩니다. 처음 설정한다면 저장소의 Settings → Pages에서 `main` 브랜치와 `/ (root)` 폴더를 선택하세요. 사용자 도메인을 연결할 경우 현재 DNS 레코드를 백업하고, 회사 이메일용 MX, SPF, DKIM, DMARC 레코드는 유지하세요.
