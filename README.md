# 서원공조시스템 홈페이지

GitHub Pages에 바로 올릴 수 있는 정적 홈페이지 기본본입니다. 반응형 회사소개, 사업분야, 시공절차, 시공사례, 참고용 간편견적 계산기가 포함되어 있습니다.

## 먼저 수정할 내용

`script.js` 상단의 `SITE_CONFIG`에 실제 전화번호, 상담시간, 서비스 지역, 사업자 정보를 입력하세요.

`ESTIMATE_RULES`의 금액은 화면 테스트용 예시이며 실제 단가가 아닙니다. 반드시 운영자의 실제 견적 기준으로 교체한 후 공개하세요. 금액 단위는 만원입니다.

`index.html`에서 회사 소개 문구와 시공 분야를 실제 업무에 맞게 수정하고, 시공사례 영역은 실제 현장사진으로 교체하는 것이 좋습니다.

## 컴퓨터에서 확인하기

폴더의 `index.html`을 더블클릭하면 기본 화면을 확인할 수 있습니다. 일부 브라우저 기능까지 점검하려면 VS Code의 Live Server 같은 로컬 서버를 권장합니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 안의 `index.html`, `styles.css`, `script.js`, `README.md`를 저장소 최상단에 업로드합니다.
3. 저장소의 `Settings` → `Pages`로 이동합니다.
4. `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/ (root)`로 선택하고 저장합니다.
6. 배포 주소가 생성되면 PC와 휴대전화에서 테스트합니다.

## owk.co.kr 연결

GitHub Pages에서 Custom domain을 설정한 뒤 도메인의 홈페이지 연결용 DNS 레코드만 변경합니다. 회사 이메일을 사용한다면 MX, SPF, DKIM, DMARC 레코드는 변경하거나 삭제하지 마세요. DNS 변경 전 현재 레코드를 반드시 백업하세요.

## AI 및 상담 접수 기능 확장

현재 견적기는 브라우저에서 정해진 기준표로 계산하는 1차 버전입니다. AI 문장 분석, 사진 분석, 고객 연락처 저장, 관리자 알림, 자동 견적서 발송을 추가하려면 서버 또는 서버리스 함수가 필요합니다. OpenAI 등 외부 API의 비밀키를 `script.js`나 GitHub 저장소에 직접 넣으면 안 됩니다.

## 개인정보 안내

현재 버전은 연락처나 사진을 서버로 전송하지 않습니다. 향후 상담 접수 기능을 연결할 때는 개인정보 수집·이용 동의문, 보유기간, 처리방침, 전송구간 암호화와 접근권한 관리를 함께 준비해야 합니다.
