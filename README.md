# 오우케이 설비 홈페이지

GitHub Pages에 바로 올릴 수 있는 정적 홈페이지입니다. 오우케이 설비의 누수 탐지·보수 전문성을 첫 화면과 사진상담 영역에서 소개하고, 저온창고 설치와 에어컨 설치·유지보수도 안내합니다. 네이버 블로그 시공사례 연결, 무료 사전견적 안내, 누수 현장사진 상담 화면이 포함되어 있습니다.

## 먼저 수정할 내용

`script.js` 상단의 `SITE_CONFIG`에 상담시간, 사업자 정보와 사진접수 주소를 입력하세요. 대표번호는 `010-3666-8255`로 반영되어 있습니다.

아파트·주택 기준의 대략적인 예상가격을 반영했습니다: 누수 공압검사 35만원, 누수 보수공사 50만원부터, 바닥면이 양호한 방수공사 평당 10만원부터. 상가·공장·사무실·농가 등 비주거 현장의 누수·방수는 숫자를 자동 계산하지 않고 현장 확인 후 별도 견적으로 안내합니다. 검사비와 보수비는 구분해 협의한 뒤 실제 단가가 확정되면 서비스·현장 유형별로 `script.js`에 반영하세요.

저온창고는 냉장·냉동 공통 평당 200만원부터와 시공비 180만원 별도입니다. 사전견적은 면적(평) × 200만원과 시공비 180만원을 분리해 보여주며 두 금액을 합산합니다. 표시된 금액은 부가세 별도이며 현장 확인 후 최종 견적이 확정됩니다. 에어컨 설치·유지보수는 단가 확정 전이므로 현장상담으로 안내합니다.

`index.html`에서 회사 소개 문구와 시공 분야를 실제 업무에 맞게 수정하고, 시공사례 영역은 실제 현장사진으로 교체하는 것이 좋습니다.

## 컴퓨터에서 확인하기

폴더의 `index.html`을 더블클릭하면 기본 화면을 확인할 수 있습니다. 일부 브라우저 기능까지 점검하려면 VS Code의 Live Server 같은 로컬 서버를 권장합니다.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 안의 `index.html`, `styles.css`, `script.js`, `README.md`를 저장소 최상단에 업로드합니다.
3. 저장소의 `Settings` → `Pages`로 이동합니다.
4. `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/ (root)`로 선택하고 저장합니다.
6. 배포 주소가 생성되면 PC와 휴대전화에서 테스트합니다.

## owk.co.kr 연결

GitHub Pages에서 Custom domain을 설정한 뒤 도메인의 홈페이지 연결용 DNS 레코드만 변경합니다. 회사 이메일을 사용한다면 MX, SPF, DKIM, DMARC 레코드는 변경하거나 삭제하지 마세요. DNS 변경 전 현재 레코드를 반드시 백업하세요.

## 사진상담 접수 연결

현재 사진선택, 파일 수·용량 검사와 미리보기까지 작동합니다. 실제 전송을 위해서는 Formspree 등 파일접수를 지원하는 서비스에서 폼을 만든 뒤 발급받은 주소를 `script.js`의 `formEndpoint`에 입력해야 합니다.

예: `formEndpoint: "https://formspree.io/f/발급코드"`

사진은 최대 5장, 장당 5MB 이하의 JPG·PNG·WebP만 받도록 화면에서 검사합니다. 접수 서비스에서도 동일한 파일 제한, 스팸 차단과 보관기간을 설정하세요. 전송 연결이 없는 동안에는 고객에게 대표번호 상담 안내가 표시됩니다.

## AI 및 상담 기능 확장

현재 사전견적 화면은 서비스별로 현장 확인사항을 안내합니다. AI 사진 분석, 관리자 알림과 자동 견적서 발송을 추가하려면 서버 또는 서버리스 함수가 필요합니다. OpenAI 등 외부 API의 비밀키를 `script.js`나 GitHub 저장소에 직접 넣으면 안 됩니다.

## 개인정보 안내

`formEndpoint`가 비어 있으면 연락처와 사진을 전송하지 않습니다. 접수 서비스를 연결할 때는 개인정보 수집·이용 동의문, 보유기간, 처리방침, 전송구간 암호화와 접근권한 관리를 함께 준비해야 합니다.
