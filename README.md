# 오우케이누수탐지 홈페이지

GitHub Pages용 정적 홈페이지입니다. 홈페이지의 소개와 메뉴는 누수 탐지·배관 보수 서비스에 집중합니다. 아파트·주택, 상가, 공장 누수 상담과 이전 시공사례를 안내합니다.

## 주요 구성

- 누수 증상별 안내 및 작업 절차
- 기숙사 배관 누수, 공장 수도배관 누수 시공사례 사진
- 주택·아파트 기준 검사·보수 비용 안내, 상가·공장은 현장 확인 후 별도 견적
- 카카오톡 채널 사진 상담 및 전화 상담

## 사진 및 상담

누수 시공 사진은 `assets/` 폴더의 기존 현장 사진을 사용합니다. 카카오톡 상담은 `index.html`의 `https://pf.kakao.com/_HxjExiX/chat` 링크를 사용합니다. 채널 주소를 변경할 때는 파일 내의 모든 카카오톡 링크를 함께 변경하세요.

상담 내용과 사진은 카카오톡 채널 채팅창에서 직접 전달받습니다. 홈페이지는 이름, 연락처, 현장 사진을 입력받거나 저장하지 않습니다.

## 운영 정보

전화번호, 상담시간 및 표시 금액은 `index.html`에서 수정하세요. 사업자 정보는 실제 정보 확인 후 추가할 수 있습니다. 사진 설명과 작업 범위도 게시 전 실제 시공 내용에 맞는지 확인하세요.

## 확인 및 배포

컴퓨터에서 `index.html`을 브라우저로 열어 화면을 확인할 수 있습니다. 저장소 최상단의 파일을 갱신하면 GitHub Pages 설정에 따라 사이트에 반영됩니다. 현재 사용자 도메인 설정 파일 `CNAME`은 그대로 유지하세요.
